# DESIGN — 밝은 구간 (전환 · 구성기 · 공방 이야기)

출처: Refero Styles "Letter — Private gallery with iridescent vault artifacts". 마지막 섹션은 Hyper Tria("크롬 덩어리와 흑백 구간 전환")를 구도로 참고한다.

## 분위기

어두운 무대(`#191b1f`)에서 밝은 편집 지면으로 넘어간다. 3D 병은 옅은 색의 "갤러리 벽" 앞에 놓인 조각처럼 보인다. 제목은 잡지 표지 같은 세리프, 본문은 넓은 산세리프로 둘로 나눈다.

## 색

| 이름 | 값 | 쓰임 |
|---|---|---|
| Vault Ink | `#191b1f` | 어두운 무대, 어두운 패널 |
| Obsidian | `#000000` | 제목·본문 글자 |
| Fog Gray | `#9fabad` | 보조 글자 배경선 등. 글자에는 대비가 모자라 `--fog-text` `#5f6b6d`를 쓴다 |
| Hairline | `#e6ebec` | 구분선, 입력칸 테두리 |
| Mist White | `#f6f9f9` | 보조 섹션 바탕 |
| Paper White | `#ffffff` | 지면 |
| Peach Wall | `#fcede1` | 향 01 새벽볕의 갤러리 벽 |
| Mint Wall | `#eefcef` | 향 02 비숲의 갤러리 벽 |
| Lavender Wall | `#e6def0` | 향 03 밤물결의 갤러리 벽 |
| Deep Teal | `#186f64` | 행동 버튼(채움) 하나와 같은 색 고스트 링크. 다른 곳에는 쓰지 않는다 |

갤러리 벽 세 색은 3D 장면 배경과 구성기 견본에만 쓴다. 넓은 지면이나 글자색으로 쓰지 않는다.

## 글자

- 제목: Hahmlet(고대비 세리프) 400~500, 자간 +0.02em. 화면 제목 `clamp(2.5rem, 1rem + 5vw, 5rem)` 행간 1.1, 섹션 제목 `clamp(1.75rem, 1rem + 2.4vw, 2.875rem)` 행간 1.2.
- 본문·UI: IBM Plex Sans KR 400, 라벨은 500. 본문 1rem 행간 1.6.
- 제목을 산세리프로 쓰지 않는다.

## 모양

- 모서리는 모두 2px. 알약 버튼, 둥근 카드 없음.
- 버튼 좌우 여백 27px. 채운 버튼 옆에는 같은 색 고스트 링크를 짝으로 둔다.
- 그림자 없음. 깊이는 바탕색 차이와 3D 렌더가 만든다.
- 3D 렌더는 테두리 없이 여백에 띄운다.

## 마지막 섹션 (Hyper Tria 구도)

- 다시 검정으로 돌아간다. 크롬 재질의 한글 워드마크 "윤슬" 하나만 둔다.
- 장식 그래픽 없음. 행동은 테두리 버튼이나 화살표 글자로만.
